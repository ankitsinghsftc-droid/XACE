# XACE Product Claims Matrix

This file is a working claims checklist derived from
`docs/XACE_PRODUCTION_READINESS_MASTER_PLAN.md`. The master plan remains the
single execution contract; this matrix exists so docs, UI labels, and launch
copy can be checked quickly.

Commercial launch-model decisions are frozen in
`docs/XACE_COMMERCIAL_SCOPE.md`. If this matrix conflicts with that record, the
commercial scope record wins until a newer signed scope record replaces it.

## Claim Rules

- Public claims must describe proven behavior, not intended architecture.
- Smoke tests prove only the scenario they run.
- Editor-free bridge proof is not the same as installed-engine production proof.
- Fake, deterministic, or contract test paths must be named as such.
- A claim blocked by this matrix can be restored only after the master-plan proof
  gate for that capability passes.

## Forbidden Public Claims

These phrases, and close variants, must not appear in public-facing docs or UI
unless they are clearly inside a "do not claim" or blocked-claims section:

- "Generate arbitrary gameplay systems."
- "Create any game from a prompt."
- "Full finished-game portability between engines."
- "Import existing Unity/Godot/Unreal gameplay automatically."
- "Export a finished game."
- "Production-grade multiplayer."
- "Deterministic runtime is fully enforced live."
- "All CGS, prompt, schema, and engine-side mutations are conflict-safe and atomic."
- "Real SGC production integration" for arbitrary generated, plugin, or external systems until those executor contracts, release-wide signing, and remote retained-CI evidence pass.
- "Secrets are securely stored."
- "Ready for non-technical public creators."
- "Ready for professional studios."
