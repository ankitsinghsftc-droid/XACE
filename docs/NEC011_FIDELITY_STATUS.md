Status: COMPLETE for the declared NEC-011 creator profile (2026-10-23). Completion receipt: `docs/evidence/nec011-completion-20261023/summary.json`. Final audit passed: 513 regression tests, all three native replacement/input probes, combined structured replay, reproducible executor source checks, and all 55 protected recovered baseline files. ## Declared profile

Windows creator hosts: Unity 6000.4.9f1, Unreal 5.7.4, Godot 4.6.3. Authoring uses the existing trusted closed-editor saved-document gateway. Review and approval are mandatory. Opt-in saved-change polling coalesces saved revisions; it does not publish changes or approve a proposal. In-memory unsaved edits and open-editor IPC are not certified. Source drift invalidates the reviewed revision. Repeated unchanged captures are no-ops. Previously verified source and presentation receipts remain retained.

`native.static_translation_hierarchy.v1` supports static parent translation, identity rotations and unit scale, in the existing fixed64 coordinate bounds. Native parent relationships remain native authoring relationships; runtime transforms are composed world coordinates with runtime parent_entity_id=0. This is not dynamic runtime parenting, arbitrary shear/rotation/scale composition, or native physics authority. Unsupported profiles remain refused. The transform helper supports 1,000 objects; the reconciliation planner still has its 128-object ceiling. NEC-017 must resolve that ceiling and certify the unchanged 1,000-object program target.

The declared native-event input profile maps explicit native selectors to `axis_1d` values in [-1,1] or buttons in {0,1}, with at most 256 distinct action names. Unity uses `XaceLiveInputBinding.nativeSelector` and `SubmitNativeAction`; Unreal uses `FXaceLiveInputBinding.NativeSelector` and its Blueprint-callable `SubmitNativeAction`; Godot uses `live_bindings[].native_selector` and `submit_native_action`. A native input callback supplies samples and release values; collection occurs on the existing authority tick request path. Empty selectors preserve the existing physical-key binding path. Unknown samples, unsupported/duplicate mappings and invalid values refuse. Stop and reconfigure the approved profile before changing mappings; native action graphs are not automatically translated into these bindings. Device-specific sampling and arbitrary native input-framework integrations are not certified by the event-profile proof.

## Readiness and resources

`native_fidelity.py` defines an approved, digest-pinned creator contract covering CGS, World, executable, input configuration, controller and presentation identities; native coordinate conventions; fixed64/60Hz profiles; role/type/required resource bindings; declared packet mappings; and runtime tick authority. Observations must come from a host-owned fresh native probe. Missing bindings, wrong axes/scale, stale identities, failed playback, unexpected native gameplay feedback or wrong input ticks block readiness. Browser declarations cannot replace the host probe.

Construct `NativeFidelityGate(contract, expected_contract_digest=approved_digest, probe=fresh_probe)` and pass it as `fidelity_gate` when configuring `NativeMaterializationHost`. The materialization application's actual Player route holds the authoring publication lock, obtains a fresh observation, checks the source again and only then invokes the underlying Player service. An unconfigured host refuses Play; stop/status remain available. The trusted probe must inventory the actual configured native project and resources; no universal automatic probe installer or native packaged lifecycle is claimed here. NEC-012 owns production native lifecycle admission; NEC-013/014/015 own engine build/export integration.

Required binding flag `xace_binding_required` prevents fallback in preflight and all three native applicators. A declared `resolved` or `fallback` string cannot hide failed playback. Optional explicitly permitted cosmetic fallback remains supported. Native animation/audio playback and resource replacement are probed using actual installed engines. Playback-state verification is not audible-device certification. Engine timing/physics cannot become authoritative gameplay through these proofs. Animation controller graphs are not translated.

These failures are not passing evidence.
